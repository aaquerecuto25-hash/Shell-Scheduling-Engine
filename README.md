# Simulador de Kernel y Gestor de Procesos en Consola (Shell & Scheduling Engine)

## Proyecto Sistemas Operativos - Fase I
Universidad Católica Andrés Bello (UCAB)  
Escuela de Ingeniería Informática  
Cátedra de Sistemas Operativos  

### Descripción
Diseño e implementación de un simulador de kernel y gestor de procesos interactivo en consola con soporte multihilo (POSIX Threads). Incluye:
- Hilo CLI interactivo para lectura y validación de comandos.
- Hilo Motor de Scheduling (CPU) con reloj simulado discreto (*clock ticks*).
- Algoritmos de planificación: Round Robin (RR) y Shortest Remaining Time First (SRTF).
- Carga de procesos por lotes (*batch mode*).
